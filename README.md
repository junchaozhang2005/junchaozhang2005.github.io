# Pure static academic homepage

This repository version intentionally does not use Jekyll or Academic Pages.

## Main files

- `index.html` — English homepage
- `zh/index.html` — Chinese homepage
- `css/style.css` — all visual styling
- `js/main.js` — theme switcher
- `images/` — personal photos and placeholder research figures
- `.nojekyll` — tells GitHub Pages to publish the files directly

## GitHub Pages setting

Use:

- Settings → Pages
- Source: Deploy from a branch
- Branch: master
- Folder: /(root)

## Placeholder images

The SVG files under `images/papers/` are temporary placeholders. Replace them later with real paper overview figures, system diagrams, or experiment screenshots while keeping the filenames unchanged.
