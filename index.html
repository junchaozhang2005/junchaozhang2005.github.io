VulCrosser: Cross-Contract Vulnerability Detection

I modeled cross-contract calls and state dependencies using dependency graphs and heterogeneous graph neural networks. The model achieved 92.81%–94.87% accuracy across three vulnerability-detection tasks.

Orion: Layer-2 Scalability under Dynamic Networks

I contributed to network modeling, protocol implementation, and evaluation using 72 cloud nodes deployed across three geographic regions.

PoSitive: Automated Simulation of PoS Incentive Vulnerabilities

I contributed to attack-scenario modeling and independently implemented the core reinforcement-learning optimization module. The evaluation covered 9,354 scenarios and approximately 145 hours of simulation.

Physics-Informed Continuous-Time Battery-State Estimation

I derived a charge-conservation ODE model and implemented a low-memory online estimator, achieving 1.13% SOC RMSE on 7,565 real discharge records with O(1) memory and approximately 0.5 ms inference latency.
