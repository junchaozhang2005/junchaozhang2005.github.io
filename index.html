Smart Contract Security and Vulnerability Detection

First-Author Research Project · Advisor: Teng Huang

Investigated vulnerability detection methods based on complex network analysis and heterogeneous graph learning for interactive smart contract scenarios.

  • Modeled cross-contract calls, state dependencies, and interactive execution relationships;
  • Designed graph-based vulnerability representations and heterogeneous graph learning modules;
  • Achieved detection accuracies of 92.81%–94.87% across three vulnerability detection tasks.
